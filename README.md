# 🧮 Calculadora Web

Calculadora simples e responsiva feita com HTML, CSS e JavaScript.

### ✨ Funcionalidades
- Soma, subtração, multiplicação e divisão
- Interface limpa e responsiva
- Botão de limpar e apagar

### 🛠️ Tecnologias
`HTML` `CSS` `JavaScript`

### ▶️ Como usar
1. Abra o arquivo `index.html` no navegador
2. Ou acesse pelo GitHub Pages
